# lightning

Agentic coding harness completely built in Rust. In-built observability into every decision and execution done using the LGTM stack. In-progress passion project, currently still at a pre-v0 stage. Plans to create a desktop application using Tauri, while also keeping the CLI default as well. Goal is to finish it by the end of 2026, let's see how long it takes.

## Status

Tools (`read_file`, `list_dir`, registry, workspace sandbox) -> working 
CLI (interactive menu) -> working 
Test suite -> not yet
LLM client (local / OpenAI-compatible (most likely using LiteLLM)) -> not yet 
GUI (Tauri) -> not yet 
Orchestrator loop -> not yet
Context management, permission gate, session store, telemetry -> not yet 

## Note

This project is completely hand-written. Despite having access to tools like Claude Code and Codex, I've missed the feeling of despair while looking at a screen full of compile errors. Also, I thought it would be a nice hands-on way to learn both Rust and observability, something I've been wanting to do for a while. 

I understand the documentation is not very developer-friendly or AI agent-friendly at this point. But I'm working on improving that as well. If there are any suggestions or improvements I can make, please let me know!
